# Contributing

Thank you for helping improve Codelanche AI.

1. Open an issue describing the change.
2. Keep scanner and graph behavior deterministic.
3. Add tests for every new parser rule or graph relationship.
4. Do not allow an agent to create unverified code references.
5. Run `uv run pytest` and `uv run ruff check .` before submitting a pull request.

Small, focused pull requests are easiest to review.
